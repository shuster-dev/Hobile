# Hobile V3 — Classic Visual Overhaul

This version replaces the block/Roblox-like prototype look with an original classic FPS visual style.

Highlights:
- Textured raycast walls: sandstone, concrete, metal and wooden crates
- Original Counter-Terrorist and Terrorist character sprites with tactical gear and rifles
- First-person rifle, pistol and knife artwork
- Weapon switching
- Muzzle flash, hit marker, damage flash and HP bars
- 3v3 bot combat, pathfinding, kills and round scoring
- Bomb/Defuse flow with Sites A & B
- Mobile joystick, touch aim, fire, reload, jump and use
- All art is original and bundled locally; no CDN / Three.js / external game assets

Create Room / Join Room remain UI placeholders until the multiplayer server milestone.
